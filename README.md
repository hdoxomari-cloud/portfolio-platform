# Creative Portfolio Platform

## About
A React-based portfolio application that allows
users to view projects, search through projects,and 
add new projects.

## Features
~ Displays a collection of projects.
~ Search projects by title.
~ Add new projects using a form.
~ View individual project details.
~ Responsive layout for different screen sizes.

## Built With
~ React
~ JavaScript
~ HTML
~ CSS
~ React Router
~ Vite
